## `~/about`

Не люблю писать код ради самого кода.

Мне интереснее собрать **полноценную систему**, где всё работает вместе:

```text
                    IDEA
                     │
                     ▼
              ┌──────────────┐
              │  ARCHITECTURE │
              └──────┬───────┘
                     │
          ┌──────────┴──────────┐
          ▼                     ▼
       FRONTEND              BACKEND
          │                     │
          └──────────┬──────────┘
                     ▼
                  DATABASE
                     │
                     ▼
                 API / BOT
                     │
                     ▼
                AUTOMATION
                     │
                     ▼
                  RESULT
```

**Моя цель простая:**

> сделать сложное — понятным, а скучное — автоматическим.
